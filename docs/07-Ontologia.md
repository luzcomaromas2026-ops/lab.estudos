# 🧬 Ontologia da Simbologia

> **Este é o coração do Laboratório de Simbologia.**
>
> Uma ontologia é um mapa de "como as coisas se relacionam". Para símbolos, ela responde: *Como um símbolo existe no mundo? Quais são suas propriedades? Como se conecta a outros?*

---

## 🎯 Por Que Uma Ontologia?

Aplicativos similares (Notion, Obsidian, Wikipedia) são **genéricos**. Você coloca dados em estruturas soltas (tabelas, páginas, texto livre).

Mas símbolos têm **estrutura própria**.

Uma coruja não é:
- Uma nota aleatória
- Uma página de Wikipedia genérica
- Uma entrada em um banco de dados relacional comum

Uma coruja é um **nó em um grafo de significado**, com propriedades, tipos de relacionamentos e contextos específicos.

**Sem ontologia clara, o Mapa de Conexões não funciona.**

Com ela, emerge a magia: padrões invisíveis ficam visíveis.

---

## 📊 A Estrutura Fundamental

Todo símbolo no Laboratório tem esta estrutura:

```
[Símbolo]
├── É um: [Tipo de símbolo]
├── Representa: [Significados]
├── Relacionado a: [Outros símbolos]
├── Aparece em: [Contextos/Tradições]
├── Origem: [Culturas/Histórico]
├── Observações Pessoais: [Seu insight]
└── Fontes: [Livros/Artigos]
```

Vamos decompor cada parte:

---

## 1️⃣ "É um" — Taxonomia de Símbolos

Classifica o **tipo** de símbolo. Múltiplas categorias são possíveis.

### Tipos Principais

| Tipo | Exemplos | Propriedades |
|------|----------|--------------|
| **Animal** | Coruja, Serpente, Leão, Águia | Tem comportamento real; significado emerge do comportamento |
| **Divindade** | Atena, Hécate, Mercúrio, Diana | Representa força arquetípica; multiface |
| **Carta de Tarô** | A Sacerdotisa, O Eremita, A Torre | Estrutura fixa (78 cartas); sistema completo |
| **Elemento** | Fogo, Água, Terra, Ar, Éter | Base de sistemas esotéricos; qualidades universais |
| **Cor** | Preto, Azul, Vermelho | Estímulo sensorial com significado cultural/psicológico |
| **Número** | 1, 3, 7, 13 | Recorrências em múltiplas tradições |
| **Planta** | Rosa, Louro, Cicuta, Mandrágora | Propriedades mágicas/medicinais históricas |
| **Cristal/Mineral** | Ametista, Quartzo Rosa, Turmalina, Ônix | Propriedades vibracionais; cores; formas cristalinas; histórico alquímico |
| **Lugar** | Labirinto, Montanha, Abismo, Templo | Espaços arquetípicos do inconsciente |
| **Ação** | Morte, Transformação, Ascensão, Queda | Processos simbólicos universais |
| **Arquétipo** | Herói, Sombra, Anima/Animus, Ancião | Estruturas psicológicas profundas (Jung) |
| **Símbolo Geométrico** | Círculo, Triângulo, Hexagrama, Mandala | Significado através da forma |

### Exemplo: Ametista (Cristal)

```
Ametista é um:
├── Cristal/Mineral (tipo primário)
├── Elemento (terra, solidificação)
└── Símbolo Geométrico (forma hexagonal)
```

### Regra Importante
Um símbolo pode ter **múltiplos tipos**:
- Lua = [Animal] + [Divindade (Deusa)] + [Elemento]
- Serpente = [Animal] + [Arquétipo] + [Divindade]
- Ametista = [Cristal/Mineral] + [Elemento] + [Símbolo Geométrico]

## 2️⃣ "Representa" — Significados

Registra **o quê** o símbolo significa. Múltiplos significados são esperados.

### Estrutura de Significado

```
Representa:
├── Significado 1
│   ├── Cultura/Tradição
│   ├── Contexto
│   └── Fonte (livro/artigo)
├── Significado 2
│   └── ...
└── Significado N
```

### Exemplo: Coruja (Animal)

```
Coruja representa:
├── Sabedoria
│   ├── Tradição: Mitologia Grega
│   ├── Contexto: Atena é a deusa da sabedoria e tem coruja como símbolo
│   └── Fonte: Bulfinch's Mythology
├── Morte
│   ├── Tradição: Folclore Celta
│   ├── Contexto: Som da coruja à noite era presságio de morte
│   └── Fonte: Celtic Mythology - Peter Ellis
├── Visão Noturna / Intuição
│   ├── Tradição: Psicologia Junguiana
│   ├── Contexto: Coruja vê no escuro = enxerga o inconsciente
│   └── Fonte: "Dreams" - Jung
└── Ilusão / Engano
    ├── Tradição: Folclore medieval
    ├── Contexto: Coruja pode se disfarçar ou confundir predadores
    └── Fonte: Bestiary Medieval
```

### Exemplo: Ametista (Cristal/Mineral)

```
Ametista representa:
├── Proteção Espiritual
│   ├── Tradição: Crystal Healing (moderna)
│   ├── Contexto: Cor roxa = vibração protetora
│   └── Fonte: "The Crystal Bible" - Judy Hall
├── Intuição e Terceiro Olho
│   ├── Tradição: New Age / Chakras
│   ├── Contexto: Roxo = coroa/terceiro olho; clarividência

├── Limpeza e Purificação
│   ├── Tradição: Alquimia e esoterismo

│   └── Fonte: Tradição oral, comunidades Wicca

│   ├── Tradição: História (nome vem do grego "amethystos" = sem embriaguez)
```

### Regra Importante
**Não elimine significados conflitantes.** Coruja = sabedoria E morte É possível. A polissemia é feature, não bug.

## 3️⃣ "Relacionado a" — Grafo de Conexões

Este é o **core do mapa visual**. Define relações a outros símbolos.

### Tipos de Relacionamentos

| Relação | Significado | Exemplo |
|---------|-----------|---------|
| `origem_de` | Vem de / deu origem a | Lua → A Sacerdotisa (Tarô) |
| `equivalente_a` | Mesmo símbolo em tradições diferentes | Atena = Minerva (latim) |
| `oposto_de` | Polaridade | Dia ↔ Noite |
| `complementar_de` | Funciona em par | Yin ↔ Yang |
| `aspecto_de` | Parte de um símbolo maior | Serpente = aspecto de Ouroboros |
| `governado_por` | Regido por divindade/força | Noite → governado_por → Lua |
| `habita` | Vive/existe em | Coruja → habita → Floresta |
| `relacionado_psicologicamente` | Conexão junguiana | Coruja → relacionado_psicologicamente → Sábio (arquétipo) |
| `sincronicidade_com` | Padrão significativo | Lua → sincronicidade_com → Ciclos menstruais |
| `expressa_qualidade_de` | Encarna uma qualidade | Leão → expressa_qualidade_de → Coragem |

### Exemplo: Mapa de Coruja

```
Coruja
├── equivalente_a → Strix (latim)
├── origem_de → A Sacerdotisa (Tarô XIX)
├── relacionado_a → Atena (divindade)
├── relacionado_a → Noite
├── relacionado_a → Lua
├── relacionado_a → Sabedoria
├── relacionado_a → Inconsciente (psicologia)
├── relacionado_a → Sábio (arquétipo)
├── complementar_de → Águia (dia ↔ noite)
├── aparece_em → Mitologia Grega
├── aparece_em → Mitologia Celta
├── aparece_em → Contos Populares Europeus
└── sincronicidade_com → Morte (em algumas tradições)
```

### Quando o Mapa Ativa

Quando você cadastra Coruja com estas conexões, o Mapa de Conexões mostra:

```
                    Mitologia Grega
                            ↓
                        Atena ← ← ← Coruja ← ← ← Sabedoria
                        /              ↑\
                   Deusa          Noite ↓ Lua
                                        ↓
                                  Inconsciente
                                        ↓
                                  A Sacerdotisa (Tarô)
                                        ↓
                                  Psicologia Junguiana
                                        ↓
                                    Sábio (Arquétipo)
```

Você vê em um olhar o que levaria 5 livros para entender.

## 4️⃣ "Aparece em" — Contextos e Tradições

Define **onde** o símbolo se manifesta.

### Tipos de Contexto

| Contexto | Descrição | Exemplos |
|----------|-----------|----------|
| **Tradição Religiosa** | Sistema de fé organizado | Mitologia Grega, Hinduísmo, Cristianismo |
| **Sistema Esotérico** | Conhecimento oculto/místico | Tarô, Alquimia, Astrologia, Cabala |
| **Tradição Indígena** | Conhecimento de povos originários | Xamanismo Amazônico, Mitologia Asteca |
| **Psicologia** | Estruturas psicológicas | Psicologia Junguiana, Arquétipos |
| **Literatura/Arte** | Cultura imaginativa | Contos de Fadas, Mitologia Celta, Ópera |
| **Natureza** | Fenômenos naturais | Astronomia, Etologia, Botânica |
| **Ciência Medieval** | Conhecimento pré-moderno | Alquimia, Astrologia Antiga, Bestiari |
| **Folclore** | Tradição oral popular | Contos Populares, Superstições |

### Exemplo: Lua Aparece em

```
Lua aparece em:
├── Mitologia Grega (Selene, Ártemis)
├── Mitologia Romana (Diana, Luna)
├── Mitologia Egípcia (Thoth, Khonsu)
├── Hinduísmo (Chandra)
├── Tarô (A Sacerdotisa - XVIII)
├── Astrologia (Lua = emoção, inconsciente)
├── Alquimia (prata, feminino)
├── Astronomia (satélite natural da Terra)
├── Ciclos Menstruais (correspondência)
├── Magia Wicca (fases lunares = poder)
└── Contos de Fadas (Bruxa da Lua, Lobisomem)
```

## 5️⃣ "Origem" — Rastreabilidade Histórica

De onde veio o símbolo? Como apareceu? Quem o usou primeiro?

### Exemplo: Serpente

```
Serpente
├── Origem geográfica: Oriente Médio, Egito, Mesoamérica
├── Período histórico: Pré-História até Presente
├── Primeira documentação: Codex Sumeriano (~2100 aC)
├── Evolução:
│   ├── Serpente venenosa (medo real)
│   ├── Serpente criadora (cosmologia babilônica)
│   ├── Serpente do Éden (cristianismo)
│   ├── Ouroboros (alquimia greco-egípcia)
│   └── Energia Kundalini (tantrismo hindu)
└── Sincretismo: Mesmo símbolo evolui em tradições diferentes
```

## 6️⃣ "Observações Pessoais" — Seu Insight

**Isto é a diferença entre Wikipedia e seu Atlas Vivo.**

Wikipedia é enciclopédia. Seu Diário do Laboratório é pesquisa.

```
Coruja - Observações Pessoais:

"24/07/2026: Encontrei conexão entre Coruja (sabedoria noturna) e 
A Sacerdotisa (XVII do Tarô). Ambas operam no conhecimento oculto, 
visão além do visível. Interessante que Atena usa coruja como escudo, 
proteção da sabedoria."

"30/07/2026: Releitura de Jung - Sábio arquétipo. Coruja não é apenas 
sabedoria, é o GUARDIÃO da sabedoria. Não compartilha fácil. Isso muda 
como vejo A Sacerdotisa - ela guarda conhecimento, não revela."

"15/08/2026: Sonho com coruja branca. Não era sábia, era assustadora. 
Reconsiderando: sabedoria em excesso afasta as pessoas? Refletir sobre 
Atena como guerreira também, não só sábia."
```

Seu Diário documenta a **evolução do seu pensamento**.

## 🗺️ Como Isto Habilita o Mapa de Conexões

Quando você tem esta ontologia para cada símbolo, o mapa visual funciona assim:

```
Algoritmo de Visualização:
1. Pega símbolo (Lua)
2. Busca todas as suas "Representações" → nós de significado
3. Busca todos os "Relacionado a" → nós de conexão
4. Busca todos os "Aparece em" → contextos
5. Renderiza como grafo visual interativo
6. Usuário clica, expande, explora

Resultado: Um grafo vivo que mostra padrões invisíveis
```

Sem esta ontologia clara, você teria apenas dados soltos. **Com ela, emerge a magia.**

## 🎯 Por Que Isto É Diferente de Obsidian/Notion

| Ferramenta | Estrutura | Força | Fraqueza |
|---|---|---|---|
| **Obsidian** | Notas + links genéricos | Flexível, pessoal | Sem semântica; usuário define tudo |
| **Wikipedia** | Artigos estruturados | Confiável, enciclopédico | Estático; não pessoal |
| **Notion** | Banco de dados genérico | Customizável | Sem semântica de símbolos |
| **Lab. Simbologia** | Ontologia de símbolos | **Semântica clara + grafo + pessoal** | Mais estruturado (feature, não bug) |

Laboratório = Obsidian + ontologia de símbolos + grafo visual

### Banco de Dados
```sql
Tabelas:
```

## 🎓 Grimórios com Registro de Estudos

### O Que É?

Um **Grimório** (caderno temático) agora pode conter **Entradas com Registros de Estudo** — um subsegmento que rastreia seu progresso de aprendizado sobre um tema específico.

### Estrutura

```
[Grimório Temático]
├── Tipo: Tarô, Sonhos, Cores, Animais, etc
├── Entradas Pessoais (múltiplas)
│   └── [Entrada Pessoal 1]
│       ├── Data: 25/07/2026
│       ├── Texto: "Investigando o simbolismo da Coruja..."
│       └── **Registro de Estudo (opcional)**
│           ├── Objetivo: "Entender origem da Coruja em 3 tradições"
│           ├── Status: em_progresso
│           ├── Progresso: 65%
│           ├── Horas investidas: 4.5
│           ├── Aprendizados: ["Atena = sabedoria", "Mitologia grega", ...]
│           └── Próximos passos: ["Comparar com Tarô", "Ver Psicologia"]
│
└── [Entrada Pessoal 2]
    ├── Data: 28/07/2026
    └── Texto: "Conclusão: Coruja representa guardião do conhecimento"
```

### Por Que?

- **Rastreabilidade**: Veja quanto tempo gastou em cada aprendizado
- **Intencionalidade**: Defina objetivos claros de estudo
- **Reflexão**: Registre aprendizados e próximos passos
- **Métrica**: Visualize progresso (% concluído)
- **Contexto**: Cada estudo fica vinculado ao Grimório + Entrada original

## 🛡️ Princípios de Design

1. **Múltiplos tipos e significados são esperados** — Não force simplicidade
2. **Polissemia é feature** — Um símbolo pode significar tudo isso
3. **Contexto importa** — Mesmo símbolo, significados diferentes em tradições diferentes
4. **Pessoal + Acadêmico** — Observações + fontes
5. **Grafo é visualização** — A ontologia é o banco de dados; o mapa é a UI
6. **Extensível** — Novos tipos de relacionamento podem ser adicionados
