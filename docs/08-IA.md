# 🤖 IA — Inteligência Artificial

**Laboratório de Simbologia — Roadmap de IA**

---

## 📌 Versão 1 (MVP): ZERO IA

**Decisão Explícita:** v1 tem ZERO machine learning.

**Por quê:**
- Símbolos são pessoais e contextuais
- IA genérica gera "alucinações" em conhecimento esotérico
- Dados de entrada insuficientes (< 100 usuários)
- Arquitetura deve suportar IA, mas não precisa dela

**O que v1 tem:**
- ✅ Search simples (full-text PostgreSQL)
- ✅ Sort/Filter manual
- ✅ Grafo baseado em relacionamentos explícitos (usuário cria)

---

## 🔮 Versão 2+ (Futuro): Possíveis Aplicações de IA

### Sugestão de Relacionamentos

**v2.1: "Você talvez queira conectar X com Y"**

```
Baseado em:
├─ Coincidência de significados (mesmo texto)
├─ Contextos similares
├─ Padrões de relacionamentos existentes
└─ (SEM generative AI, lógica determinística)

Implementação:
└─ PostgreSQL query simples, não ML
```

### Geração de Conexões (CONTROVERSO)

**v2.2: "Posso sugerir conexões baseado em padrões?"**

```
❌ NÃO fazer:
├─ "IA pensa que X significa Y" (hallucinations)
├─ Gerar novos significados
└─ Criar relacionamentos fictícios

✅ Possível fazer:
├─ Sugerir usuários revisem conectividade
├─ Identificar gaps óbvios
└─ Avisar "Lua está isolada, adicione conexões"
```

### Busca por Similaridade Semântica

**v3.0: "Símbolos similares"**

```
Embeddings de texto (OpenAI API):
├─ Converter descrições → vetores
├─ Busca por cosine similarity
└─ "Símbolos como este"

Implementação:
└─ pgvector (PostgreSQL vector extension)

Custo:
└─ ~$0.01 por 1000 tokens (OpenAI)
```

---

## 🚫 O que NUNCA Fazer

### Generative AI

❌ **Não gerar significados:** "IA pensa que Coruja é símbolo de X"
❌ **Não criar fichas automáticas**
❌ **Não editar conteúdo de usuário**
❌ **Não fazer interpretações pessoais** do Diário do usuário

### Perfilagem

❌ **Não criar perfil psicológico** baseado em símbolos
❌ **Não recomendar** "você gostaria de Y símbolo"
❌ **Não vender dados** para modelos de IA

---

## 🔒 Ética & Privacidade (Se Houver IA)

```
Se usar IA:
├─ User opt-in explícito ("Ativar sugestões?")
├─ Dados não treinados em model externo
├─ Local-first quando possível (transformers.js)
├─ Transparência total ("Sugestão gerada por IA")
└─ Direito de desativar qualquer feature IA
```

---

## 📊 Métricas para Avaliar IA

Se implementarmos:

```
Qualitativas:
├─ "Sugestão foi útil?" (thumbs up/down)
├─ "Descobriu conexão nova?" (yes/no)
└─ Feedback qualitativo

Quantitativas:
├─ Taxa de aceitação de sugestões
├─ Tempo economizado por usuário
└─ Criação de relacionamentos após sugestão
```
