# 🎭 UX — User Experience & Flows

**Laboratório de Simbologia — Fluxos de Usuário**

---

## 📌 Personas & Goals

### Persona 1: O Pesquisador (Mari, 32 anos)
- **Goal:** Pesquisar símbolos sem perder conexões
- **Flow Principal:** Buscar Lua → ver significados → descobrir conexões com A Sacerdotisa
- **Tempo/Sessão:** 30-60 min, múltiplas sessões
- **Device:** Mobile + Web

### Persona 2: O Iniciante (João, 24 anos)
- **Goal:** Aprender sobre tarô de forma estruturada
- **Flow Principal:** Abrir Grimório do Tarô → explorar 78 cartas → ler significados
- **Tempo/Sessão:** 15-30 min, dias alternados
- **Device:** Primariamente Mobile

### Persona 3: O Artista (Ana, 28 anos)
- **Goal:** Achar inspiração de símbolos para design
- **Flow Principal:** Buscar "cores" → ver relacionamentos → salvar favoritos
- **Tempo/Sessão:** 10-20 min, sessões curtas
- **Device:** Mobile

## 🎯 User Journeys

### Journey 1: Primeiro Login (Onboarding)

```
1. Sign up (Google/GitHub) → Aula 1: "O que é Laboratório?"
2. Ver 5 constelações (Observatório)
3. Clicar em BIBLIOTECA → Intro
4. Clicar em GRIMÓRIOS → Intro
5. Clicar em FICHAS → Criar primeira ficha
6. Explorar Mapa → Entender relacionamentos
7. Escrever no Diário → Completar onboarding

⏱️ Tempo: 5-10 min
🎯 Goal: Entender conceito + curiosidade
```

### Journey 2: Pesquisar um Símbolo (Core Flow)

```
1. Abrir app → Observatório visível
2. Clicar em 🔍 FICHAS
3. Buscar "Coruja"
4. Ver ficha (tipos, significados)
5. Clicar em "Mapa" (ícone de grafo)
6. Explorar grafo (Coruja → Atena → Sabedoria)
7. Clicar em "A Sacerdotisa" (novo nó)
8. Ver relação entre Coruja e A Sacerdotisa
9. Adicionar observação no Diário
10. Voltar ao Observatório

⏱️ Tempo: 20-30 min
🎯 Goal: Descobrir conexão oculta
```

### Journey 3: Adicionar Livro na Biblioteca

```
1. Clicar em 📚 BIBLIOTECA
2. Clicar "Adicionar Livro"
3. Preencher:
   - Título: "Dreams" - Carl Jung
   - Autor: Carl Jung
   - Tema: Psicologia
   - Resumo: [texto livre]
   - Rating: ⭐⭐⭐⭐⭐
4. Upload PDF (opcional)
5. Tag símbolos (Lua, Arquétipos, Inconsciente)
6. Salvar

⏱️ Tempo: 5-10 min
🎯 Goal: Centralizar referências
```

### Journey 4: Criar Grimório Customizado

```
1. Clicar em 📜 GRIMÓRIOS
2. "Novo Grimório"
3. Escolher tipo (ou criar custom)
4. Primeira entrada:
   - Título: "Lua na minha vida"
   - Conteúdo: [reflexão pessoal]
   - Data: [hoje]
   - Tags: lua, inconsciente, pessoal
5. Salvar
6. Voltar para ver timeline

⏱️ Tempo: 10 min
🎯 Goal: Documentar reflexão pessoal
```

### Journey 5: Rastrear Progresso de Estudo

```
1. Clicar em 📜 GRIMÓRIOS
2. Abrir Grimório "Tarô"
3. Ver entrada: "Os Arcanos Maiores"
4. Tap em "Registro de Estudo"
5. Ver:
   - Objetivo: "Memorizar 22 Arcanos em 4 tradições"
   - Status: em_progresso
   - Progresso: 65%
   - Horas investidas: 8.5h
   - Aprendizados: ["O Mago = Poder Pessoal", ...]
   - Próximos passos: ["Estudar Menores", ...]
6. Tap "+ Atualizar" para incrementar progresso
7. Preencher:
   - Horas mais: 1.5
   - Novo aprendizado: "Sequência = padrão iniciático"
   - Status: ainda em_progresso (65% → 75%)
8. Salvar

⏱️ Tempo: 5 min
🎯 Goal: Manter visualização de progresso de aprendizado
```

## 🎬 Animações & Transitions

### Mudança de Constelação

```
1. Usuário toca em 📜 GRIMÓRIOS
2. Current content faz fade out (150ms)
3. Novo conteúdo faz fade in (150ms)
4. 📜 ícone faz scale 1.1 → 1 (200ms ease-out)

Sensação: Suave, intencional, sem distração
```

### Abertura de Detalhes

```
Modal abre com:
├─ Fade in overlay (100ms)
├─ Content slide up (200ms, ease-out-cubic)
└─ Focus no primeiro campo

Fecha com:
├─ Slide down (150ms)
└─ Fade out (100ms)
```

### Grafo (Mapa de Conexões)

```
Ao carregar:
├─ Fade in dos nós (500ms, staggered 50ms cada)
├─ Fade in das linhas de relação
└─ Subtle scale animation (1.0 → 1.02 → 1.0)

Hover em nó:
├─ Scale 1.1 (150ms)
├─ Highlight color do nó
└─ Mostrar label

Tap em nó:
├─ Navigate para detalhe
└─ Smooth transition
```

## 🎯 Micro-interações

### Search (Fichas)

```
Usuário digita "lua":
1. Instantly filter symbols (< 100ms)
2. Highlight match em nome
3. Mostrar count ("12 resultados")
4. Clear search com X button
5. Quando vazio, voltar ao list completo
```

### Favoritar Símbolo

```
Usuário toca ⭐:
1. Icon faz scale 1.2 → 1 (200ms)
2. Mudança de cor (empty → filled)
3. Toast: "Adicionado aos favoritos"
4. Desaparecer automático (2s)
5. Item move para topo da lista
```

### Criar Nova Ficha

```
Ao salvar:
1. Button fica disabled
2. Spinner animado
3. Sucesso → toast "Símbolo criado"
4. Auto-close modal (1s delay)
5. Return para lista
6. Novo item aparece com destaque (pulse 200ms)
```

## 📊 Fluxo de Onboarding

```
1. Welcome (1 min)
   └─ "O Laboratório é seu espaço para pesquisar símbolos"

2. Observatório (1 min)
   └─ "Aqui estão as 5 constelações de conhecimento"

3. Fichas (2 min)
   └─ Criar primeira ficha (ex: "Sol")

4. Mapa (1 min)
   └─ "Veja como símbolos se conectam"

5. Diário (1 min)
   └─ "Registre suas reflexões"

Total: ~6 min
Skip sempre disponível
Pode revisitar depois em Help
```

## 🚪 Exit Flows

### Confirmação de Deletar Símbolo

```
Modal:
├─ Título: "Apagar Lua?"
├─ Texto: "Esta ação não pode ser desfeita"
├─ Button: [Cancelar] [Apagar]
└─ Default: Cancelar (focus)

Após deletar:
├─ Toast: "Símbolo apagado"
└─ Return para lista
```

### Logout

```
Simple logout:
├─ Menu → Logout
├─ Confirm: "Tem certeza?"
└─ Clear session + return home
```
