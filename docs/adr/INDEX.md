# Índice de ADRs

Este arquivo lista as Architecture Decision Records (ADRs) do projeto, com links diretos para cada decisão registrada.

Como usar

- Ao criar uma nova ADR, adicione um item a este índice no formato abaixo e salve a cópia da ADR em `docs/adr/` nomeada com o padrão `NNNN-titulo.md` (ex.: `0001-uso-postgres.md`).

Formato de entrada recomendado

- `0001 — Título da decisão` — YYYY‑MM‑DD — status (proposta/aprovada/recusada) — aprovador

Exemplo

- `0001 — Escolha do banco relacional` — 2026‑07‑24 — aprovada — Usuária X

Boas práticas

- Use números sequenciais com 4 dígitos para ordenar (`0001`, `0002`, ...).
- Registre autor e data no topo da ADR e atualize o índice quando o status mudar para aprovado.
- Mantenha o texto da ADR conciso: contexto, decisão, alternativas e impacto.

Local das ADRs

- `docs/adr/` — templates e arquivos concretos das decisões arquiteturais.
